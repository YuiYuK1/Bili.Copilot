# 登录体验

哔哩助理为了减小开发困难，被设计成登录后才能使用。

在第一次打开应用时，会弹出登录框。

![登录](./assets/zh/sign-in.png)

## 扫码登录

应用推荐使用扫码登录，你可以用你的移动客户端扫描登录界面右侧的二维码，并在移动客户端上确认以登录。

确认后，应用会自动重启。

## 网页登录

如果你想要以其它方式登录，比如手机号，或者账户密码等。

那么你可以点击左侧LOGO下方的网页登录按钮。

此时你会跳转到网页登录界面，在完成登录后，应用会检测你的 cookies，然后生成访问令牌，并完成登录。

## 手动登录（实验性）

> [!WARNING]
> 该功能目前标记为实验性：应用需要把网页 Cookie 换成云视听小电视的访问令牌，这个服务端接口近期会拒绝部分请求（返回 `-101 账号未登录`），即使 Cookie 本身有效也可能登录失败。请优先使用扫码登录；相关排查见下方「关于用户凭据」。

如果你已经在浏览器里登录过哔哩哔哩，也可以尝试直接复用浏览器里的 Cookie 完成登录，不必再扫码或打开网页登录窗口：

1. 在浏览器中打开并登录 [bilibili.com](https://www.bilibili.com)。
2. 按 `F12` 打开开发者工具，切换到「网络 / Network」并刷新页面。
3. 选中任意一个 `www.bilibili.com` 的请求，在「请求标头 / Request Headers」中找到 `Cookie`，复制它的完整值。
4. 回到登录窗口，点击「手动登录（实验性）」，把内容粘贴进输入框并确认。

> [!IMPORTANT]
> 粘贴内容中必须包含 `SESSDATA` 与 `bili_jct`，否则应用无法完成登录。Cookie 等同于你的登录凭据，请勿分享给他人。

登录过程中应用会显示进度，成功后会自动重启。

## 关于用户凭据

哔哩助理作为第三方应用，仅能根据网上可以找到的信息尝试构建应用，开发者最终选择以云视听小电视（TV版BiliBili）的API来构建应用。

所以不论你是扫码登录、网页登录还是手动登录，最终你的用户凭据都会被转换成适用于云视听小电视的访问令牌（Access Token），由于还有部分 API 必须访问网页版本，所以应用也会存储 cookies 信息，以便于进行网页API的授权验证。

这些信息保存在本机的应用数据设置中（`ApplicationData.Current.LocalSettings` 的 `BiliKernel` 容器）：

| 键 | 内容 |
| --- | --- |
| `BiliUserTokenInfo` | 访问令牌、刷新令牌与过期时间（JSON） |
| `BiliUserCookies` | 网页接口使用的 Cookie（JSON） |

它们不会被上传到开发者服务器；点击 `退出账户` 或卸载应用时会被一并清除。网页登录窗口使用的 WebView2 也会在自己的用户数据目录中保留浏览器 Cookie，该目录独立于上述设置。

> [!WARNING]
> 尽管大部分 API 可以工作，但是云视听小电视的API有一个已知问题，那就是动态请求无法获取到关于专栏文章的内容。
> 这个是由B站服务器控制的，开发者无能为力。

## 退出登录

如果你需要退出账户，可以在应用顶部头像处打开个人菜单，然后点击 `退出账户` 即可。

![退出账户](./assets/zh/sign-out.png)
